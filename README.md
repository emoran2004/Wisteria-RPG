# Wisteria: A Fairy's Tale — Chapter 1

Native **Godot 4.x** GDScript starter project. No Phaser, JavaScript, or external art assets.

## Run
1. Open Godot 4.
2. Click **Import** and choose `project.godot`.
3. Open the project and press **F6** on `scenes/level.tscn` or **F5** to play.

## Controls
- A/D or arrow keys: walk
- Space/W/up: jump (Space uses Godot's default `ui_accept` mapping)
- E: free the fairy when standing near the crystal and holding all 3 petals
- R: restart
